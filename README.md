# CMP7005 Programming for Data Analysis

## PRAC1 – From Data to Application Development

This repository contains the development work for the CMP7005 Programming for Data Analysis practical assessment.

The project analyses loan application data, performs exploratory data analysis and preprocessing, develops machine-learning models, and integrates the final modelling solution into a graphical user interface.

## Project Structure

- `data/` – Raw loan datasets
- `notebooks/` – Data analysis and machine-learning notebooks
- `src/` – Application source code
- `models/` – Exported trained models
- `screenshots/` – Evidence and application screenshots
